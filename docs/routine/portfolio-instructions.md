# The portfolio

This project holds no code. It is where the person keeps the morning
routine's log while running every other project by hand for two weeks
(`docs/PLAN-portfolio.md`, slice 1, in the aigentic fork).

The person reads the briefs with `scripts/routine-briefs.sh` and pastes
what matters here. A thread in this project cannot read briefs in other
workspaces, so answer from what was pasted. If something is missing,
say so: a gap like that is a finding for the log.

Each morning the person adds an entry to
`.aigentic/knowledge/routine-log.md` in the format at the top of that
file. Help fill it in when asked. Do not rewrite earlier entries.
